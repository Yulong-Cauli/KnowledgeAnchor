## 1. frontmatter 规则

- 不动：`id`、`type`、`status`（保持 asserted）、`tags`、`note`、`paper`、`stance`、`review_due`、`signoff`。
- `title` 可精简：一句话主张 + 决定结论的关键条件；不改变命题本身（样例：qlora 卡把平写 "2k+1" 修正为已核对的 "2^k+1"——改写读法必须有原文 alttext 级证据，否则保留平写）。
- `scope` 推荐顺序：数据集与 split → 模型/配置 → 比较基线 → 指标口径 → 证据来源与抓取日期 → "尚未独立验证"。对照方法的数字细节（如同表其他行成绩）移正文，不入 scope。
- `evidence`：优先 library 笔记 quote（逐字 + Grep 验证，locator 给章节）；保留的 arXiv 句 locator 必须带抓取日期；新增外部来源（官方实现、原文 alttext）必须记录 URL+抓取日期。数字一律不改写。
- `falsifiers` 分层标注：原文核查 / 同范围复现（主张侧）/ 同范围复现（对照侧）/ 假设或最优性核对（理论卡）/ 跨条件迁移（不充当原范围反证）。配置不一致的对照复现不判伪，降级为"口径问题登记待决"。效应阈值要有锚点（如基线论文数字），无依据标待定。

## 2. 正文结构（七节推荐，可合并省略，不凑满）

`## 这条主张是什么意思`（2–3 句：问题/主张/为何值得理解 + asserted 声明）
`## 证据支持到哪里`（哪条 quote 支撑哪部分；区分论文报告 vs 独立复现；写明证据边界如单源抓取/未开源）
`## 可能的解释与未排除的因素`（理论卡可改 `## 假设与推导`：作者解释 / 行为观察 / 替代解释分层，整理者推断显式标注）
`## 适用范围与迁移限制`（scope 中真正影响结论的条件；跨模型/跨口径外推一律移此节）
`## 对研究问题的启发`（显式标"尚未验证的研究假设"；不替用户指定研究方向）
`## 当前立场与下一步`（stance 依据未记录就写"按未记录处理"；下一步按四要素：区分什么/改变固定什么/观察什么/结果如何改变判断；区分四类检查：原文核查/同范围复现/机制辨别/跨条件迁移）
`## 核查记录`（按日期；本轮仅表达整理就如实写"表达整理，数字未改写"）

## 3. 内容纪律（P1 每卡检查单）

1. asserted 一律"论文声称 / 尚未独立验证"表述，不得写成事实。
2. 不把自己的因果解释归给作者：作者解释、行为观察、替代解释分清；整理者推断标"（本班整理者…，尚未验证）"。
3. **scope 扩大是本班首要故障模式**：影响分析约束回 scope 配置；"换模型/换数据集会怎样"移迁移节，不留在结论段。
4. 历史引文：*-note-table-mismatch 卡与带「笔记已修正」「待主人裁定」附注的卡，旧引文只作历史记录保留（明确标记），状态决策留主人。
5. 数学符号不凭记忆修复：平写有歧义（如 2k+1）→ 实抓原文 alttext 定读法，核不了标待核。
6. 六问检查（发现了什么/证据支持到哪里/为什么+其他解释/条件下限/什么检查能区分/结果如何改变判断）——按需分布在小节里，不为凑问灌水；信息完整而简短的卡**原样保留**计"已审阅保留"。
7. 拆卡：仅限已有准确来源、能独立成立的主张；新卡 asserted + related 双向 + scope/falsifiers 齐备；旧卡 id/命题不动。无据拆分 → 待决。
8. library/ 只读：发现笔记问题写待决清单；本班发现的待决转 QUESTIONS（自 #49 起编号，#48 已用）。
9. 返回摘要必须给三计数：改动 X / 原样保留 Y / 待决 Z，改动卡逐张列 id + 改动类型 + 来源核对范围。
