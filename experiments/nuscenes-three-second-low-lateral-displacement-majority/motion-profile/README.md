# nuScenes 短时自车运动分布补充统计

## 问题与范围

扩展已有“约3秒后横向位移<2m”的单点统计，给出横向位移完整分布、速度分布及按速度分组的横向位移分布。覆盖nuScenes v1.0全部1000段记录，沿用完整未来六个keyframe的34157个样本窗口。分别报告全部、trainval、train、val、test，不修改此前定义、原始结果或claim状态。

设计日期：2026-11-08。本轮是已有探索后的描述性扩展，以下定义、速度分组和输出在本次运行前固定；不预先指定结论方向，不选择有利的速度组，不作独立样本显著性检验。关联卡 `claim-nuscenes-three-second-low-lateral-displacement-majority` 仍为asserted / watch；本轮先补数据，不预先改写锚点主张。

## 测量定义

- 横向位移：沿用原测量函数，未来六步终点至当前航向参考线的绝对垂直距离，单位米。另列整个窗口内的最大绝对横向位移。
- **窗口平均速度**：未来六段XY路径长度之和，除以该窗口的真实时间跨度，单位m/s；不是首末点直线距离除以时间。
- **起点速度估计**：起点与前一个keyframe的XY距离，除以两者实际时间差。它描述起点之前约0.5秒的平均速度，作为起点附近速度的估计，不冒称CAN bus实测瞬时速度。每段记录首帧没有前一帧，不补零、不用未来速度代填，单列缺失；预计当前速度统计33157个、缺失1000个，实际从链验证。
- 速度同时给出m/s与km/h（×3.6）。平均速度与起点速度各自统计，分母与缺失数显式列出。

## 固定输出

1. 两种横向位移和两种速度的分布：样本数、均值、总体标准差、min、P10、P25、P50、P75、P90、P95、P99、max；分位数采用线性插值`h=(n-1)q`，不沿用之前的四舍五入索引近似。
2. 横向位移严格小于 `{0.1,0.25,0.5,1,1.5,2,3,5,10}` 米的整数计数与比例。每个速度组使用全部同一网格，不按结果增删。
3. 两种速度均按 `[0,0.5)、[0.5,2)、[2,5)、[5,10)、[10,15)、[15,20)、[20,+∞)` m/s 分组；左闭右开。保留空组、组内样本数与场景数。每组给横向位移P50/P90/P95及上述全部阈值比例。它们不同于前轮按路径长定义的停止/低速组，不能混用名称。
4. 输出完整经验累计分布（ECDF），同时提供`<x`与`≤x`计数，避免等值边界混淆。全量逐样本表保留样本token、场景、split、原运动指标、两种速度、起点前一帧时间差及缺失原因。
5. 另列固定的≥5、≥10、≥15、≥20m/s聚合组，帮助读取较高速度范围；不是事后挑选。所有结果按两种速度定义、各split分别完整输出。
