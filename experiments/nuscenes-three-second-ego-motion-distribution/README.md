实验目录和文档链接随卡片 ID 迁移。已执行的代码、协议、notebook、日志及结果仍按运行时版本归档，文件中的旧 ID 对应同一次实验。

当前范围扩展至nuScenes v1.0全部1000段驾驶记录，包括训练、验证、测试集。观察每个时刻随后约3秒的运动；记录末尾无法提供完整后续轨迹的时刻不计入统计。

“横向位移小”是指：从车辆当前位置沿车头朝向画一条直线，约3秒后，车辆位置到这条直线的距离小于2米。先分别报告三个集合，再按样本数量合并。定义与阈值沿用前次，详见 [本轮扩展设计](all-splits/README.md)；结果见 [RESULTS](RESULTS.md)。

## 单一主张与口径

主张：nuScenes **v1.0-trainval** 中，具有完整未来六个 keyframe 的样本，未来终点相对当前 ego 航向线的绝对横向位移 **<2m** 者占多数（严格 **>50%**）。报告精确整数分子、分母、未舍入比例；不要求接近 73.9%、87% 或其他目标值。

train 700 场景 / val 150 场景分别列出，合并 850 场景为主总体。150 个 test 场景不在范围。“六步”按 keyframe 链定义，名义约 3 秒；真实 LIDAR 时间戳跨度另报，不将不规则采样强行称为恰好 3.000 秒。

使用 LIDAR_TOP keyframe 对应的 **ego_pose 原点**（不加传感器外参），global XY 位置、当前四元数投影 yaw。设末点与当前点之差为 `(dx,dy)`，`y_end = -sin(yaw0)*dx + cos(yaw0)*dy`。主判据为 `abs(y_end)<2`，边界等于 2m 不计入。该定义是本项目的可复算描述，不冒称作者直行命令的原实现。

若合并总体占比 ≤50%，主张被反例推翻；若任一 split 不过半，必须明确报告该 split 的反例，不能泛称各 split 均主导。若数据完整性失败或镜像与官方关键文件哈希不一致，停止解释，不以排除异常来维持主张。

## 解释检查与全量输出

1. 移动状态按六段 XY 路径总长划分：stopped ≤0.3m；low_speed 为 (0.3,1.5]m；moving >1.5m。它们是操作性分组，不是人工驾驶状态真值。另列 non_stopped（>0.3m），避免把低速和正常移动混为一类。
2. 对每组报告主比例、窗口内最大绝对横向位移 <2m 的比例，以及末点 <2m 但中途 ≥2m 的数量。停止样本不从主总体隐式删除。
3. 所有组扫描末点/最大横向位移 {0.5,1,2,3}m，累计绝对 yaw 变化 {3,5,10,15,20,30}°，只展示敏感性，不再通过择取阈值认定论文复现。
4. 航向双法诊断：仅当六段位移均 >0.3m 时，将六段位移方向的累计变化与六个区间中点插值 yaw 的累计变化相比（两者均为五次差分）；报告累计值差 >15° 的样本数、合格分母及排除数。不是旧代码的“多数步夹角冲突”，也不是全数据质量认证。
5. 按场景列样本数和主比例，报告等场景权重均值及分布；主结果仍按样本计数。重叠窗口不是独立随机试验，不给无意义的独立样本显著性结论。

`census.py` 为计算源；`build_notebook.py` 把同一源码、固定 splits 与启动来源信息嵌入 notebook。Kaggle CPU 执行；所有尝试与失败均留在 `RUNS.md`，不修改旧原始结果。
