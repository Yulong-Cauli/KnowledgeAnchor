# 结果：nuScenes 全部1000段记录的低横向位移统计

本库对 nuScenes v1.0 的普查结果。关联卡 `claim-nuscenes-three-second-ego-motion-distribution`（asserted / adopt）。

## 1. 补上测试集后的结果

沿用同一定义：从车辆当前位置沿车头朝向画一条直线，未来约3秒后的位置离这条直线不足2米，就计为横向位移小。每段记录末尾没有完整后续六个采样点的时刻不计入。

| 数据范围 | 满足条件 / 有效样本 | 占比 |
| --- | --- | --- |
| 训练集 | 20908 / 23930 | 87.371500% |
| 验证集 | 4501 / 5119 | 87.927330% |
| 测试集（本轮新增） | 4374 / 5108 | 85.630384% |
| 此前训练+验证 | 25409 / 29049 | 87.469448% |
| 三个集合合并 | 29783 / 34157 | 87.194426% |

测试集占比为85.630384%，比训练/验证合并值低1.839064个百分点。合并后为29783/34157 = **87.194426%**；三个集合分别统计也都超过一半。合并时相加整数分子和分母，没有平均三个百分比。

这支持“按本定义，低横向位移的运动窗口占多数”的描述；不表明87%的整段场景简单，也不证明感知需求或模型捷径机制。

## 2. 停止、低速与移动样本

沿用前轮分组：约3秒内路径总长≤0.3米为停止，0.3–1.5米为低速，>1.5米为移动。它们是计算分组，不是人工驾驶意图标注。

| 数据范围 | 排除停止和低速后的满足/分母 | 占比 |
| --- | --- | --- |
| 训练集 | 16459 / 19481 | 84.487449% |
| 验证集 | 3700 / 4318 | 85.687818% |
| 测试集 | 3804 / 4538 | 83.825474% |
| 三个集合合并 | 23963 / 28337 | 84.564350% |

全量停止组4946个、低速组874个，均满足主条件。只去掉停止组时为24837/29211 = 85.026189%；同时去掉停止与低速后为23963/28337 = **84.564350%**。所以总体多数观察不完全由停车/低速样本贡献；这仍是分组描述，不是因果实验。

在2米阈值下，整个窗口最大横向偏移<2米的分子也为29783；终点小于2米但中途达到2米的样本为0。其他阈值均完整保存在敏感性表中，不通过择取阈值追逐论文百分比。

## 3. 数据范围与来源

- 训练700段、验证150段、测试150段，共1000段。全部40157个采样时刻中，34157个有完整未来六步；每段末尾6个时刻共6000个不计入。测试集实际链计数为6008个时刻、5108个完整窗口，排除900个末尾时刻。
- 测试集直接读取官方 v1.0-test 元数据包，不依赖镜像、不需要隐藏评测标注。150个场景与固定官方test名单完全一致；462901条sample_data、462901条ego_pose。LIDAR与样本一一对应、链归属/prev/next、位姿引用、时间戳和单位四元数检查通过，无缺LIDAR而遗漏的样本。
- 训练/验证部分复用前次逐样本结果，读取前检查原CSV、原结果JSON、原官方比对记录的SHA256；全部29049行逐样本指标及15个原汇总在本次收割后再次确认未变。前次四表与官方包逐字节一致的证据保持原样。

## 4. 时间跨度和场景差异

- 全量未来六步实际时长：2.649800–3.400703秒，中位数2.999815秒；93个窗口在3±0.25秒之外。测试集为2.748598–3.350377秒，中位数2.999817秒，14个窗口超出该带。全部保留，不为贴合3秒而择样本，因此只称“约3秒”。
- 全量1000段记录各自的主比例范围为8.823529%–100%，p05=52.941176%，中位数100%，按记录等权均值87.183323%。所以不能声称每一段记录都以低横向位移为主。
- 航向双法诊断：测试集4339个窗口满足每步位移>0.3米的条件，769个不参与；累计变化差>15°为0/4339，最大差3.754534°。全量符合条件26633个，排除7524个，>15°为0，最大差6.716057°。这只是同一运动诊断，不是数据整体质量认证。
