## 班 A：bevplanner 直行占比统计复算（Kaggle CPU）

对应卡主张（论文声称，尚未独立验证）：nuScenes 73.9% 的数据是直行场景。本班只攻 falsifier 第 1 条（统计复算）；falsifier 2（因果隔离）不在范围。

### 预注册（写码之前，阈值以本节为准，落 README 后不得回调）

- 主口径：样本级未来 3s（sample.next 链 6 个 keyframe @2Hz）ego 轨迹直行判定，三判据族：
  H = 累计|Δheading| ∈ {3,5,10,15,20,30}°；L = 横向偏移 ∈ {0.5,1,2,3} m；P = 逐点|Δheading| 全 <5°
- **触发 falsifier 1（证伪级）**：全部判据×阈值×split 下直行占比均 <60%（卡内预设判据）
- **带内复得（证据级支持）**：存在预注册判据使 trainval 样本级占比 ∈ [68.9%,78.9%]（73.9±5pp）
- **附录口径复得（证据级支持）**：val 样本级占比 ∈ [82%,92%]（87±5pp，对齐论文"87% of evaluation samples"，附录 E）
- 其余落点：如实记录、不定性、留主人裁定
- 本实验为全量普查无抽样随机性；以"同一场景重算两次结果逐位一致"作确定性断言
- 任何偏离口径（元数据不全、判据实现差异等）必须在 README 与 RESULTS.md 显式标注，区分证伪级/证据级

### 状态机
