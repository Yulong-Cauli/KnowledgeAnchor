# 图谱视图交互细化实施方案（二期第一批 + 第二批）

> 面向下游实现 Agent 的完整实施说明。目标：把 `#/graph` 图谱从"能看"提升到"能用"——补上聚焦、定位、导出三个日常交互，新增主题版图模式与到期描边。
>
> 本文档只描述本批方案。实施前请先通读 `AGENTS.md`、`tmp_docs/ka-web-ui-design.md`（一期设计，§6 与 §10 与本文直接相关）、`web/app.js` 的图谱段（`// ---- graph --` 注释起，约 L1030-L1536）、`tools/serve.mjs` 的 `buildGraph()`（约 L381-L444）。
>
> **本批不需要改 `tools/serve.mjs`**：`/api/graph` 的 payload 已携带全部所需字段（note 节点有 `path`，claim 节点有 `status / stance / tags / review_due`）。

## 0. 背景与现状（实现的出发点）

### 0.1 现有实现速览

- 数据：`GET /api/graph` 返回 `{nodes, edges, counts}`。节点 `kind` 为 `note`（菱形，id 形如 `note:library/...md`）或 `claim`（圆点，status 着色）。边只有两种 `kind`：`note`（归属）与 `related`（无向、无语义）。
- 前端：`buildGraphView(data)` 一次性搭建画布，自写 O(n²) 力导向模拟（斥力带 800px 截断、按边 kind 分两档弹簧、弱向心力），`alpha` 热量驱动 `requestAnimationFrame`，`alpha < 0.02` 后停帧。
- 已有交互：拖节点、空白拖拽平移、滚轮以光标为中心缩放、hover tooltip + 邻域淡化、单击 claim 跳详情、单击 note 做 sticky 高亮（`focusNote`）、点空白取消、`#graph-relayout` 重新布局、`#graph-mode` 切换 hubs / related。
- 关键机制（实施时复用，不要另起炉灶）：
  - `pos: Map<id,{x,y,vx,vy}>` 跨筛选保留位置（`ensurePos`，L1109）。
  - `view = {zoom, panX, panY, autoFit}`；`autoFit` 期间每帧向适配 bbox 缓动（L1299-L1310 的 0.9/0.1 插值模式）。
  - `neighbors: Map<id, Set<id>>` 在 `refilter()` 内重建（L1151-L1156 的 `bump`）。
  - `dimming / highlight / isNeighbor` 三件套（L1315-L1320）已支撑"悬停淡化非邻域"。
  - `graphRuntime = {canvas, pause, refilter, onWindowUp}`：路由离开再回来、或筛选变化时复用同一 runtime；`buildGraphView` 开头有 `window.removeEventListener('mouseup', graphRuntime.onWindowUp)` 的清理先例（L1070）。
- 筛选联动：顶栏搜索写入 `state.q`，触发 `renderGraph()` → `graphRuntime.refilter()`（L1049-L1052），**q 的变化必然流经 refilter**——这是"搜索定位"的挂接点。

## 1. 公共改造：聚焦状态泛化 + 相机动画目标 + 持续重绘钩子

A/B/C 都依赖三处小的基础改造，先做掉，后续各节直接引用。

### 1.1 `focusNote` 泛化为 `focusId`

- 现状：`let focusNote = null`（L1117）只对 note 生效。
- 改法：改名 `focusId`，语义变为"任意节点的 sticky 聚焦"。全函数内替换引用（`refilter` 的 `n.id === focusNote`、`draw` 的 focusSet/`isNeighbor`/`dimming`、click 处理、mode 切换时的清零）。`set_active` 中 `activeNotes` 的保留条件 `n.id === focusNote` 同步改为 `focusId`——注意 hubs 模式下若 `focusId` 是 claim，该 claim 本身就在 activeClaims 里，无需额外保留；只有当 `focusId` 是 note 时才需要原有的保留逻辑，行为自然兼容。
- 对外无行为变化：单击 note 仍是"聚焦/取消聚焦"（`focusId = focusId === hit.id ? null : hit.id`）。

### 1.2 相机目标 `view.target`

- 现状：`autoFit` 是唯一自动运镜，且用户一碰就永久关闭。
- 改法：`view` 增加字段 `target: null | {zoom, panX, panY}`。在 `draw()` 的 autoFit 块之后插入：

```js
if (!view.autoFit && view.target) {
  const t = view.target;
  view.zoom = view.zoom * 0.85 + t.zoom * 0.15;
  view.panX = view.panX * 0.85 + t.panX * 0.15;
  view.panY = view.panY * 0.85 + t.panY * 0.15;
  if (Math.abs(view.zoom - t.zoom) < 0.01 && Math.hypot(view.panX - t.panX, view.panY - t.panY) < 2) view.target = null;
  else kick(0); // 未收敛则继续重绘
}
```

- 用户拖拽平移 / 滚轮缩放 / 拖节点的入口处统一 `view.target = null`（三处：panning 分支、wheel 处理器、mousedown 命中节点分支），保证人手优先。
- 工具函数 `flyToNodes(idSet, {minZoom = 1.2, maxZoom = 2.4} = {})`：取节点世界坐标 bbox，按 autoFit 同款公式算 zoom/pan（限幅到 `[minZoom, maxZoom]`），写入 `view.target`，`view.autoFit = false`，`kick(0)`。B 和 A 都调它。

### 1.3 持续重绘钩子（脉冲动画前提）

- 现状：`loop()` 只在 `alpha > 0` 时 tick+续帧（L1375-L1380），静态画面不重绘。
- 改法：引入 `let animUntil = 0`（`performance.now()` 时间戳）。`loop()` 改为：

```js
function loop() {
  raf = 0;
  if (alpha > 0) tick();
  draw();
  if (alpha > 0 || performance.now() < animUntil) kick(0);
}
```

- `draw()` 内做时间动画的代码（脉冲圈）以 `performance.now()` 为相位源；需要动画的调用方设置 `animUntil = performance.now() + 时长` 并 `kick(0)`。

## 2. A：claim 自我网络聚焦（右键聚焦）

### 2.1 交互规约

| 动作 | 行为 |
|---|---|
| 单击 claim | 跳详情（**保持现状**，不加延时、不改道） |
| 右键 claim / note | `focusId = focusId === id ? null : id`（聚焦或取消） |
| 单击 note | 聚焦/取消（**保持现状**，与右键等价） |
| 双击 note | 跳笔记页（见 §4） |
| 单击空白 | 清除 `focusId`（**保持现状**） |
| Esc | 清除 `focusId`（新增） |

右键用 `contextmenu` 事件：`event.preventDefault()` 后复用 `pick(event)`。注意 mousedown 右键也会触发 panning 分支——在 `mousedown` 里加 `if (event.button !== 0) return;`，把左键以外的按钮挡在拖拽/平移之外。

### 2.2 聚焦渲染

- 复用 `dimming / isNeighbor` 机制，无需新画法和隐藏节点——淡化即聚焦，位置稳定比显隐更重要。
- 聚焦期间在被聚焦节点外圈画一圈 `var(--brand)` 细环（lineWidth 1.5，半径 `node.r + 5`），让它在淡化背景中可辨认。
- 视口左上角加聚焦指示 chip（绝对定位在 `.graph-wrap` 内，新增 DOM）：`聚焦中：{标题截断 20 字} · Esc 退出`，右侧一个 `×` 按钮等价于 Esc。新样式类 `.graph-focus-chip`，token 用 `--surface` / `--border` / `--text-muted`，`pointer-events: auto`。

### 2.3 Esc 监听与清理

- `window.addEventListener('keydown', onKeyDown)`，处理器首行：`if ((location.hash || '#/queue') !== '#/graph') return;`（离开图谱后是廉价 no-op）。
- 防重复注册：与 `onWindowUp` 同款模式——`onKeyDown` 挂到 `graphRuntime` 上，`buildGraphView` 开头统一 `window.removeEventListener('keydown', graphRuntime.onKeyDown)`（先做存在性判断）。
- Esc：`focusId = null; kick(0.2);`。

## 3. B：搜索定位（居中 + 脉冲）

### 3.1 触发与判定

- 挂接点：`refilter()` 内。`graphRuntime` 所在闭包加 `let lastQ = null`；`refilter()` 末尾比较 `state.q.trim() !== lastQ`，变了才执行定位逻辑，然后更新 `lastQ`。这样拖筛选 checkbox 不会反复运镜，只有关键词变化才触发。
- 判定：`q` 非空时，取 `refilter()` 已经算出的 `activeClaims`（hubs 模式）或 `active`（related 模式）作为命中集——**注意**：这里的"命中"是"筛选后可见"，与 q 语义一致，不需要另算。命中数 ∈ [1, 5] 才定位；>5 只筛不飞；=0 不动（`#graph-sub` 的计数文案已能说明）。
- `q` 清空时清空脉冲集，不运镜。

### 3.2 运镜与脉冲

- 运镜：调 §1.2 的 `flyToNodes(命中 id 集)`。
- 脉冲：`pulseSet = new Map<id, number>`（id → 起始 `performance.now()`），命中节点全部写入；`animUntil = performance.now() + 1600; kick(0);`。
- `draw()` 节点循环内，若 `pulseSet.has(node.id)`：相位 `t = (now - start) / 1600`，`t >= 1` 则删除并跳过；否则画扩张环——半径 `node.r + 4 + t * 14`，`globalAlpha = (1 - t) * 0.8`，`strokeStyle = cssVar('--brand')`，lineWidth 1.5。
- hubs 模式下命中 claim 时其父 note 也会因 `noteHasVisible` 可见，只脉冲 claim 本身。

### 3.3 边界情况

- 定位期间用户滚轮/拖拽：`view.target` 被 §1.2 清掉，脉冲播完即止，不打架。
- 路由在 fetch 或动画期间离开图谱：现有 `hash !== '#/graph'` 守卫已覆盖；脉冲 Map 随 runtime 重建自然消亡。

## 4. C：双击笔记跳笔记页

- `canvas.addEventListener('dblclick', ...)`：`pick(event)` 命中 `kind === 'note'` 的节点时 `location.hash = '#/note/' + encodeURIComponent(node.path)`（note 节点 payload 自带 `path`）。
- claim 单击即跳走，不存在"双击 claim"场景，dblclick 里对 claim 直接 return。
- 冲突排查：note 的单击是聚焦，不跳转，所以 dblclick 的前两次 click 只会切换聚焦态，无副作用；实现时无需 click 延时计时器。
- 图例提示文案改为：`拖拽平移 · 滚轮缩放 · 右键聚焦 · 双击笔记打开`。

## 5. F：导出 PNG

- `#graph-relayout` 旁加按钮 `#graph-export`，文案"导出 PNG"，`class="btn btn-sm"`。
- 实现（必须新建合成画布，当前画布背景透明，直接导出会透明底）：

```js
$('#graph-export').addEventListener('click', () => {
  const out = document.createElement('canvas');
  out.width = canvas.width; out.height = canvas.height; // 设备像素，天然高清
  const octx = out.getContext('2d');
  octx.fillStyle = cssVar('--surface') || '#ffffff';
  octx.fillRect(0, 0, out.width, out.height);
  octx.drawImage(canvas, 0, 0);
  out.toBlob((blob) => {
    if (!blob) return;
    const a = document.createElement('a');
    a.href = URL.createObjectURL(blob);
    a.download = `knowledgeanchor-graph-${state.meta?.today ?? new Date().toISOString().slice(0, 10)}.png`;
    a.click();
    URL.revokeObjectURL(a.href);
  }, 'image/png');
});
```

- 导出内容即当前所见（含淡化、聚焦态），不做"导出时重置视角"——所见即所得更可预期。
- 暗色主题下导出暗底图是预期行为，不强制转亮。

## 6. I：主题版图模式（第三种 graph-mode）

### 6.1 模式定义

- `#graph-mode` 增加 `<option value="topics">主题版图</option>`，持久化沿用现有 `graphMode` 模块变量。
- 语义：按 `library/` 一级目录（如 `VLM_VLA`、`BEV_Detection`）把 claim 聚成团，回答"各研究领域积累了多少、verified 覆盖如何"。
- **只画 claim 节点 + related 边**，不画 note 节点（归属信息已由空间聚类表达；要看笔记归属请回 hubs 模式）。

### 6.2 聚类归属

- `refilter()` 新增 `mode === 'topics'` 分支：
  1. claim → note：`claimIdNote`（现有 Map，L1201-L1207）。
  2. note id `note:library/<目录>/...` → topic 取 `path.split('/')[1]`；`claimIdNote` 无记录的 claim 归入 `'（无笔记）'`。
  3. 对每个可见 claim 得 topic；按 topic 分组得 `Map<topic, claimIds>`。

### 6.3 布局

- 聚类质心：topic 按成员数降序排序，质心均匀放在半径 `Rc = Math.max(200, Math.min(720, 90 * Math.sqrt(可见 claim 数)))` 的圆周上，第一个从正上方起顺时针。质心表 `Map<topic, {x, y}>` 在 `set_active` 调用前算好存入闭包。
- 种子：claim 种子 = 所属质心 + ±60 随机抖动（沿用 `ensurePos` 保位机制，筛选切换不跳变）。
- 力学：`tick()` 在 topics 模式下，把现有全局向心力 `-node.x * 0.0035` 替换为指向所属质心的力：`(cx - node.x) * 0.01`。斥力取 related 档（2600）；只保留 `kind === 'related'` 的边参与弹簧（topics 模式下 `refilter` 本来就只放 related 边）。团间自然分开靠斥力截断，不额外加团间斥力。
- 质心标签：`draw()` 内在每个质心处画 topic 名 + 计数（如 `VLM_VLA · 23`），`textAlign: 'center'`，颜色 `--text-muted`，`globalAlpha 0.6`，字号 12px，恒显示（不随缩放级别隐藏）。质心不画节点图形。

### 6.4 与其他机制的兼容

- 聚焦/搜索/脉冲/导出在 topics 模式下全部照常工作（都操作 claim 节点，无特例）。
- `focusId` 若指向 note 时切到 topics 模式：mode 切换处理器本就有 `focusId = null`（原 `focusNote = null`），保持。
- `#graph-sub` 文案：`显示 N claim · M related 边 · K 个主题`。

## 7. D：到期未复核虚线描边

- 判定：`node.kind === 'claim' && node.review_due && state.meta?.today && node.review_due <= state.meta.today`。**不做 status 区分**（asserted/stale 天然在队列里，再加"待复核"含义全是噪音；虚线圈只陈述一个中性事实：这张卡到了复核日）。
- 画法：节点填充画完后，若满足条件，同圆心画半径 `node.r + 3.5` 的圆环：`strokeStyle = cssVar('--text-muted')`，lineWidth 1.3，`ctx.setLineDash([3, 3])`，画完 `setLineDash([])` 复位。三种模式通用，淡化态下环跟随节点的 `globalAlpha`。
- 图例加一行：`<span class="lg"><i class="ring"></i>已到复核日</span>`；`.graph-legend .ring` 样式：8px 圆、1.3px dashed border、颜色 `var(--text-muted)`。
- **禁止红色/琥珀色**：token 只用 `--text-muted`，与设计文档 §1 约束 3 一致。
