## 2. 调度设计：统一火次执行器 × 滚动池（做完转轮询）

每火次统一执行（不按小时分角色；多火合并到达时按同一份 POOL 处理一次即可）：

| 步 | 动作 |
| --- | --- |
| 0 | `date` 取实际时间；读 `nightshift/verify/POOL.md`：mtime <40 分钟 → 上一位值班者在跑，立即退出零消耗 |

**轮询模式**（POOL.md 标 `mode: polling`，即全部 kernel done/blocked 后自动进入，班次转换时把 mode 字段改掉并 commit）：

- 不写 ⛔、不收摊——automation 持续 fire（5 火/天），每火做：① BLOCKED 项解除条件重试（B 的规则 push 重试、K-lsq ckpt 可得性复查、K-env 新结论对 BLOCKED kernel 的复核）；② 全量 kernel status sweep 防漏收；③ 有动作或状态变化 → 当日晨报追加一节；全无动作 → 退出零消耗。
- 轮询模式**不自动停机**，持续至主人手动删 automation 或在 POOL.md 写 ⛔（唯一停机开关，主人专用）。
- 全部红线（预注册不回调、单 kernel 重推 ≤2 次、卡只动核查记录）在轮询模式同样生效。

调度器细则：

## 3. 总则（全部 kernel 适用）

- **预注册先于 push**：每 kernel 的判定带写入 EXP/README 并单独 commit（`nightshift: preregister <slug>`），运行后不得回调。判定带唯一来源 = 对应卡 falsifiers/scope 锚点（§4 已抄录关键带）；init 时把卡面 falsifiers 全文照录进 README 再细化。卡面无定量锚点的（pointnetpillars×2、归因类检查），判据按 §4 **本次预注册**执行并显式标注「预设判据，非卡面锚点」。
- **诚实分层**：任何偏离论文/官方口径（校准池子集化、硬件差异、config 不明、缩范围）在 README 与 RESULTS.md 显式标注；结论区分「证伪级」（falsifier 预设判据命中）与「证据级」（方向性/跨口径观察）。命中 falsifier → 卡核查记录如实登记，拆卡/降级/维持留主人。
- 卡片只动「核查记录」节一行；id/status/stance/review_due/signoff/evidence/falsifiers 一律不动。QUESTIONS 分槽见 §2。
- **第三方镜像纪律（班 A 教训）**：schema 先探针后写码——sample_data 缺 `channel` 字段用 filename `__<CHANNEL>__` 段判定、rotation `[w,x,y,z]` 列表双兼容、挂载布局用剪枝 os.walk 定位；未验证数据源不引入。
- **openmmlab 系前提**：凡依赖 mmdet/mmcv/mmdet3d 的 kernel（K-bevdet/K-bevplanner/K-unidad/K-fcos/K-points 若走 mmdet），push 前提是 K-env 探针结论已入库，版本 pin 照探针结论写死在 kernel 首格；探针不可行的组合不得临场试错烧 T4。

### K-probe-1（CPU 机制探针·结构侧，~1h；EXP 主目录 `experiments/pointnetpillars-pointnet-permutation-invariance-symmetric-function/`，关联卡 maxpool-skeleton、mobilenet-dsc）

- **P1 置换不变性（pointnetpillars 卡 1）**：按论文 formulation 实现共享 MLP + maxpool 的 PointNet（合成点云分类任务，协议写死：样本数/点数/epochs/seed 全固化，val acc ≥95% 才用该模型做探针）；每测试样本随机重排 20 次：全部 |Δlogit|∞ <1e-6（CPU float32 逐位一致）→ 支持卡主张；任一次 >1e-3 → falsifier 1 方向命中登记；1e-6–1e-3 区间如实记数值噪声观察。
- **P2 骨架鲁棒性（maxpool 卡 1/2）**：定位各特征维 top-k 响应骨架点（k 预注册 = 全部），仅对非骨架点（≤10% 点数）加 σ=点半径 5% 的高斯噪声与随机删除两种扰动：全局特征相对 L2 变化 **<5% 且分类不变率 ≥95%** → 支持「骨架」论证（预设判据，非卡面锚点）；反超 → falsifier 1 方向登记。同实验跑 mean/sum 聚合对照：max 的敏感度不应高于二者（反超 → falsifier 2 方向登记）。
- **P3 代码核查（两卡 falsifier 2/3 共用）**：clone 官方 charlesq34/pointnet，核对逐点 MLP 权重共享与对称聚合实现，结论落 README（闭合「实现不符」分支）。
- **P4 mobilenet-dsc（纯算术）**：① 式(2)/(5) 恒等式：约简比 = 1/N + 1/D_K²，对 N∈{72,…,1024} 复算比值落在 [8.0×, 9.0×] → 支持 8–9×；② Table 4 重建：按 V1 1.0 架构（224 输入）逐层 Mult-Adds 求和，与 4866M/569M 各差 **<2%** → 内部自洽支持，比值 8.6× 复核；差 >5% → 如实记录差异（falsifier 2 的计算量侧方向，不判死）。top-1 差 1.1 点属复训主张，**本探针不做复训**，README 标注「仅计算量侧，精度侧不在范围」。

### K-probe-2（CPU 机制探针·计数侧，~1h；EXP 主目录 `experiments/njusparseocc-rayiou-penalizes-thick-surface/`，关联卡 qlora-nf4、sparseocc-flops）
