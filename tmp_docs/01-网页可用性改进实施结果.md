- 笔记按 note/evidence.source 列出明确引用的 claim，规范路径、去锚点、去重并区分引用类型；claim 详情可返回笔记/证据源。既有 nightshift Markdown 证据通过受限原文件接口查看，不列作 L1 笔记。
- 今日复核分为今日待办、以后处理、未安排、全部未验证、待用户处理。统一使用服务端 today；调度只改 review_due，不改知识状态、立场或签署。CLI review 仍是完整待关注清单。
- 详情默认阅读，显式编辑；只提交有变化的字段。页内对话框保护未保存内容，失败保留输入；表单保存附带文件版本检查。亮暗主题、手机导航与原图谱保留。
- Markdown 关闭任意 HTML，另兼容安全图片及简单居中容器；KaTeX 禁用受信任命令并限制展开/尺寸。链接过滤危险协议，资源检查真实目录边界及目录链接；第三方库固定版本、本地托管并保存许可证与发布包完整性值。

## 隔离写入与安全验收

所有创建、编辑、调度、恶意内容均在临时夹具中进行，未在真实 claims/library 中创建测试材料。

- 真实 HTTP 创建/保存入口：合法卡可重新读取，文件名/id 一致，索引含新卡；缺失或空白标题/scope/evidence/falsifiers、无效来源/日期/关联 id、重复 id、目标文件冲突及已有库非法均拒绝。拒绝前后卡片与索引一致。
- 标题单字段编辑保留其他字段和其他卡片原始字节；旧版本保存返回冲突。readonly、verified/stale/refuted 的编辑及调度全部拒绝。
- 夹具覆盖 asserted 的过去/今天/未来/无日期、verified 的到期/未到期、stale/refuted。日期测试含跨年、跨月和闰日。完成/顺延后今日待办减少，重新读取保持一致；受保护卡及 signoff 原始字节不变，普通浏览不写入。
- 实际网页夹具：新建失败保留输入；合法新建后计数从 5 到 6，详情默认阅读；编辑失败保留输入，成功后回到阅读；未保存时可选择继续编辑。完成及顺延使今日从 2 张变为 0，刷新后仍为 0，后续分类能找回。
- 两种空态分别检查：今日真正为空，以及全库此分类有 4 张但筛选后为 0。stale 实际页面仅显示阅读按钮，不显示调度或编辑按钮。
- 路径穿越、编码穿越、反斜杠、空字节、无效编码、目录外 junction、危险协议均拒绝。正常中文/空格资源与证据文件可读取。夹具脚本显示为文本，DOM 内无嵌入脚本或 javascript 链接。
- 浏览器关闭/整页刷新使用 beforeunload 原生提示；本轮未自动操作浏览器级离开提示。页内离开保护已实测。该差异不代表提供草稿恢复。

## 已知限制

- 搜索为确定性文本匹配，没有 PDF 全文、OCR、联网检索或生成式问答；搜索上下文保存在本次页面会话，整页刷新不恢复。
- 支持标准 Markdown 表格与 KaTeX 公式，任意 HTML 排版、非标准多表头等仍可能按原文文本显示；没有把源文中的排版/数学问题自动修成另一种内容。其他远程图片仍需网络。
- 外部编辑冲突检查是尽力检测，不能替代文件锁；多进程写入在检查与落盘之间仍有竞态。不提供多客户端协作或完整草稿恢复。
- 当前服务仍无账号认证，启动与受信任网络使用方式见根 README。代码更新后，已运行的服务需重启才能加载新服务端代码。
