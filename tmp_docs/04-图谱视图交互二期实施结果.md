## 3. 实测中记录的行为说明（非缺陷）

1. **搜索飞行后的余热漂移**：`refilter` 的 `kick(0.45)` 会让布局在 1–3 秒内继续微调，飞行目标按调用时坐标计算，故搜索后节点可能滑离正中一小段后静止（间隔 2s 三次探针位置完全一致）。方案未要求追踪漂移，实际使用中图通常已稳定，影响很小。
2. **切换模式不重置视角**：从 hubs（zoom 2.4 视角）切 topics 会保留旧视角，"重新布局"可复位。方案未规定模式切换时的运镜，维持现状。
3. 测试工具面：IAB 自动化对空字符串 `fill("")` 是 no-op、对 12px 小按钮 locator click 超时——均为自动化 API 限制，真实鼠标路径实测正常。
